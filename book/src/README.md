# Roanix Internals

Roanix is an operating system designed around a monolithic kernel written in [Rust](https://rust-lang.org).

> The name "Roanix" combines "Roan" and "UNIX". Roan refers to Roan Mountain, located on the North Carolina/Tennessee border in the United States, which serves as the namesake for this project.

This book serves as a comprehensive guide to the design and implementation of the kernel and is split into 2 sections. The first section focuses on user-related information, such as build instructions and contributor guides. The second section focuses on the technical aspects of the kernel's architecture.

For in-depth technical details, the Rustdoc-generated documentation might be more suitable. You can access it [here](https://example.com).
